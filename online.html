New to multiplayer? How to play
  1. Choose a room code and display name, then select Join room.
  2. Use Copy invite link to invite up to three other people. Everyone joins using their own browser.
  3. The room host selects Host: deal round. Each connected player with enough virtual chips enters with a 25-chip wager.
  4. When it is your turn, choose Hit, Stand, Double, Split, or Surrender if the action is enabled. If the dealer shows an Ace, select Insurance or Skip Insurance.
  5. After the round ends, the host can deal again. Virtual chips have no cash value.

Connection lost? Rejoin the same room in this browser to reclaim your previous seat. A disconnected active hand is automatically stood to keep the game moving.

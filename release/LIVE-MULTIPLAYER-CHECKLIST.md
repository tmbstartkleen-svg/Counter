# Live multiplayer certification

1. Open the public `/online.html` URL in two independent browsers or devices.
2. Choose one shared room code; each user joins with a different name.
3. Confirm both online indicators appear and the host deals a round.
4. Verify players see the same shared cards, active turn, dealer hole-card state and results.
5. Test hit, stand, double, split, surrender and insurance with eligible hands.
6. Disconnect one device, reconnect with its original browser tab, and verify seat recovery.
7. Repeat on a narrow mobile viewport and verify no controls are inaccessible.

Only play-money credits are supported. No live video, voice, public matchmaking or real-money play is implemented.

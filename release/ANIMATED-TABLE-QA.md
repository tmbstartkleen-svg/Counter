# Animated live blackjack acceptance checklist

1. Open `/online.html` on two independent devices.
2. Join the same private room with distinct human players and verify visible seats.
3. Start a round and confirm card animations, dealer cards, active seat and chip wagers update for both players.
4. Disconnect and reconnect a player; verify seat state and no phantom player.
5. Check narrow mobile widths and reduced-motion preference.
6. Ensure animations never change authoritative gameplay, chip balances, or turn sequence.

Virtual chips only. Release must pass GitHub CI and live multiplayer smoke testing before being considered certified.
